ПАНОРАМНЫЙ ТУР 360°

Состав:
  dist/index.html        — страница тура
  dist/panoramas/        — исходные панорамы

Размещение на хостинге:
1. Загрузите содержимое папки dist в корневую папку сайта.
2. Не изменяйте структуру папки panoramas.
3. Открывайте тур через адрес сайта (http/https), а не двойным щелчком по HTML.

Локальная проверка:
  В папке dist запустите простой локальный сервер, например:
  python -m http.server 8000
  Затем откройте http://localhost:8000

Управление:
  Мышь/палец — обзор
  Колесо или кнопки +/− — масштаб
  Золотые точки — переходы между сценами
  Меню внизу слева — список всех панорам
